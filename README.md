# AgroManager Pilot — QA Web Build 0.11.8.94

Статическая QA-сборка AgroManager Pilot для ручного тестирования через браузер / ChatGPT Work Cloud Browser.

## Важно

- Игровая логика основана на Windows-релизе 0.11.8.94.
- Отличие QA Web Build: файловый save API Windows-лаунчера заменён на browser `localStorage`.
- Автосохранение и ручное сохранение работают только в текущем браузере и домене GitHub Pages.
- `/session` и `/quit` отключены, потому что Go-лаунчер в статической сборке отсутствует.
- Это тестовая web-сборка, а не основной релиз игры.

## Запуск

После включения GitHub Pages откройте опубликованный URL репозитория.

Полный сценарий тестирования находится в `QA_TASK.md`.
